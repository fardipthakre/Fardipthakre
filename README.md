# FARDIP THAKRE Tools – All-in-One Calculator Suite

![Logo](icon-192.png)

> एक उन्नत कैलकुलेटर और उपयोगिता ऐप – खासतौर पर **कपड़ा, फोम, SIP, EMI, BMI, आयु गणना, यूनिट कन्वर्टर** आदि के लिए।

🌐 **लाइव डेमो:** [https://fardipthakre.github.io/Key-fabrics-smart-calculator/](https://fardipthakre.github.io/Key-fabrics-smart-calculator/)

## ✨ विशेषताएँ

- 🧮 **साइंटिफिक कैलकुलेटर** (बेसिक + साइंटिफिक मोड)
- 📏 **यूनिट कन्वर्टर** (लंबाई, वजन, आयतन, कपड़ा, तापमान)
- 🛏️ **फोम डेंसिटी कैलकुलेटर** (घनत्व गणना और ग्रेड)
- ⚖️ **फोम रेट कंपेयर** (स्थानीय vs ब्रांडेड दर)
- 👕 **फैब्रिक मास्टर** (GSM, मीटर, वज़न, आवश्यकता गणना)
- 📈 **SIP और स्टेप-अप SIP कैलकुलेटर**
- 💰 **EMI कैलकुलेटर**
- ⚖️ **BMI कैलकुलेटर**
- 📅 **आयु कैलकुलेटर**
- 📜 **हिस्ट्री सेव और एक्सपोर्ट** (CSV, JSON, TXT)
- 🎨 **थीम और क्लिक साउंड** (डार्क/लाइट/ओरिजिनल)
- 📱 **PWA सपोर्ट** (ऑफलाइन इस्तेमाल और इंस्टॉल करने योग्य)
